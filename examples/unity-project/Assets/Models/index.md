# Models

Placeholder FBX meshes, stored as plain files. Pivot at floor contact, +Z forward, unit scale; collision meshes are named `<Name>_Col` inside the same file.

## Files

* [Airship.fbx](Airship.fbx) - placeholder cube mesh standing in for the player airship (the design calls for an LOD group and Socket_* transforms).
* [Chest.fbx](Chest.fbx) - placeholder pyramid mesh standing in for the 24-slot storage container prop.
